# Palindrome-in-C-

This program preforms checks on your typed in number or character string and checks it if its a Palindrome or not. 
Palindromes are words (or sequence of numbers) that are read the same both forwards and backwards.

For example:
Race car - r a c e c a r 
Taco cat- t a c o c a t
555333333555 - 5 5 5 3 3 3 3 3 3 5 5 5

It will be a fun little program for you, so make sure you have all the joy and fun!
